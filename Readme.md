# URL Shortener

A simple URL shortener application built with TypeScript, Node.js, React.js, Express.js, and MongoDB. This project allows users to shorten long URLs and redirect them to the original destination.

## Features

- Shorten long URLs to a custom or random short URL.
- Redirect users to the original URL when accessing the shortened URL.
- View analytics for each shortened URL (such as the number of clicks).
- Simple, intuitive front-end interface built with React.js.

## Technologies Used

- **Frontend**: React.js, TypeScript
- **Backend**: Node.js, Express.js, TypeScript
- **Database**: MongoDB
- **URL Shortening**: Hashing and encoding techniques like NanoId
- **Environment Management**: `.env` for environment variables
